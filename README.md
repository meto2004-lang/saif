# كم — منصة تعلّم الحوسبة الكمية

موقع تعليمي تفاعلي عربي (مع نسخة إنجليزية كاملة) يشرح الحوسبة الكمية لطلاب المرحلة الثانوية عبر الشرح المبسّط، ومحاكي **Quirk** الحقيقي، والأنشطة، والاختبارات، وأوراق عمل جاهزة للمعلم.

> مشروع مُعدّ للمشاركة في معرض ومسابقة **سيف** — الرياض، 24–26 نوفمبر 2026.

## الفكرة في سطرين

الحوسبة الكمية تُدرَّس غالباً نظرياً وبمعادلات مجردة، فيصعب على الطالب تكوين حدس صحيح عنها.
هذا الموقع يحوّل المفاهيم (الكيوبت، التراكب، التشابك، القياس، البوابات) إلى تجارب يراها الطالب ويتفاعل معها مباشرة داخل المتصفح، ويقيس فهمه فوراً.

## ما يميز المشروع

- **تعلّم بالممارسة:** كل مفهوم مرتبط بدائرة جاهزة تُفتح في محاكي Quirk بضغطة واحدة.
- **محتوى عربي أصيل:** شرح عربي مبسّط مع المصطلح الإنجليزي المقابل، لا ترجمة آلية.
- **تغذية راجعة فورية:** 4 أنشطة تفاعلية + اختبار من 20 سؤالاً مع تصحيح لحظي وشرح لكل إجابة.
- **جاهز للمعلم:** أهداف درس، 3 أوراق عمل قابلة للطباعة، 10 أسئلة تقويم، وأنشطة صفية.
- **مساعد تعليمي:** يجيب عن أسئلة الطالب ويقترح تجربة مناسبة ويحمّلها في المختبر.
- **ثنائي اللغة وRTL/LTR:** تبديل كامل بين العربية والإنجليزية مع تغيير اتجاه الصفحة.
- **يعمل دون تثبيت:** ملفات ثابتة (HTML/CSS/JS) تعمل من أي متصفح، وتعمل واجهتها وأنشطتها المحلية حتى عند انقطاع الإنترنت (محاكي Quirk نفسه يحتاج اتصالاً).
- **ملائم للجوال:** قائمة جانبية منسدلة وتخطيطات متجاوبة.

## الأقسام

| # | القسم | المحتوى |
|---|-------|---------|
| 0 | عن المشروع | المشكلة، الحل، الابتكار، الأثر، مسار التعلّم (افهم ← جرّب ← تحقّق)، والتقنيات — بطاقة مختصرة للجنة التحكيم |
| 1 | الرئيسية | مقدمة، إحصاءات، كرة بلوك متحركة |
| 2 | المفاهيم الأساسية | 6 بطاقات: الكيوبت، البت مقابل الكيوبت، التراكب، التشابك، القياس، البوابات + شرح تفاعلي داخل نافذة |
| 3 | مختبر Quirk | 5 دوائر جاهزة، 6 تجارب مشروحة خطوة بخطوة، ومحاكي مضمّن |
| 4 | البوابات الكمية | 8 بوابات: المصفوفة، الوظيفة، مثال عملي، زر «جرّب في Quirk» |
| 5 | الأنشطة | توقع H، بناء حالة بيل، اختر البوابة، بناء دائرة بالسحب والإفلات |
| 6 | الاختبارات | 20 سؤالاً مع نتيجة نهائية ورسالة تشجيعية |
| 7 | المشاريع | 4 مشاريع صغيرة قابلة للتنفيذ داخل Quirk |
| 8 | قسم المعلم | أهداف، أوراق عمل للطباعة، تقويم، أنشطة صفية |

## التشغيل

لا يحتاج الموقع إلى أي بناء أو تثبيت:

```bash
# الطريقة الأسهل
open index.html          # أو انقر مزدوجاً على الملف

# أو عبر خادم محلي (مستحسن لتفادي قيود file:// في بعض المتصفحات)
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## هيكل الملفات

```
index.html        بنية الصفحة (RTL) وكل الأقسام
css/style.css     التصميم الكامل: الوضع الداكن/الفاتح، التجاوب، الطباعة
js/data.js        المحتوى: المفاهيم، البوابات، التجارب، الاختبار، المشاريع، أوراق العمل
js/app.js         المنطق: اللغة، الثيم، المحاكي المحلي، الأنشطة، الاختبار، المساعد
```

المحتوى مفصول عن المنطق: لتعديل أي نص أو سؤال أو دائرة يكفي تحرير `js/data.js`.

## التقنيات

HTML5 · CSS3 (متغيرات، Grid، Flexbox، RTL منطقي) · JavaScript خالص (بدون مكتبات) · Canvas API · Web Storage · [Quirk](https://algassert.com/quirk) لعرض الدوائر الكمية · مخططات SVG مضمّنة.

## سيناريو عرض مقترح (3 دقائق)

1. **المشكلة (20 ثانية):** «كيف نشرح الكيوبت لطالب لم يرَ معادلة كمومية؟»
2. **الحل (20 ثانية):** افتح الرئيسية، ثم بطاقة «التراكب» → مثال تفاعلي يغيّر زاوية الحالة ويعرض الاحتمالات.
3. **الممارسة (60 ثانية):** المختبر → تجربة حالة بيل → شغّلها في Quirk → لاحظ أن النتائج 00 أو 11 فقط.
4. **التحقق (40 ثانية):** نشاط «ابنِ حالة بيل» ثم سؤالان من الاختبار ليظهر التصحيح الفوري.
5. **الأثر (20 ثانية):** قسم المعلم (أوراق عمل قابلة للطباعة) + المساعد التعليمي + دعم العربية والإنجليزية.
6. **الخاتمة (20 ثانية):** «منصة تصل لأي طالب عبر رابط واحد، وتعمل على أي جهاز دون تثبيت.»

### نصائح لليوم نفسه

- اختبر الإنترنت في الجناح مبكراً؛ إن كان ضعيفاً استخدم الأنشطة المحلية والاختبار (لا تحتاج شبكة).
- افتح الموقع في تبويب واحد مكبّر (Ctrl/Cmd +) وضعه في وضع ملء الشاشة.
- جهّز رابط GitHub Pages في رمز QR على بطاقة أو شاشة.

## ملاحظات

- محاكي Quirk يُضمَّن من `algassert.com`، ويُحمَّل كل رابط دائرة بمعامل `?v=` لضمان تحديث الدائرة.
- الواجهة تحفظ اللغة والوضع الليلي محلياً، وتعمل حتى لو كان التخزين المحلي معطّلاً.
- الطباعة مخصّصة لأوراق العمل وأسئلة التقويم فقط.
