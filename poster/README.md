# الملصق العلمي — كم | SAIF 2026

ملصق على **قالب سيف الرسمي**، بمقاس **36 × 48 بوصة** (914 × 1219 مم، طولي)، وبخط **IBM Plex Sans Arabic** المعتمد.

## الملفات

| الملف | الوصف |
|-------|-------|
| `saif-poster-36x48.pdf` | **الملف الجاهز للطباعة** — 927 KB، متجهي بالكامل |
| `saif-poster-36x48.jpg` | نسخة صورة 150dpi للرفع في بوابة المسابقة أو المشاركة |
| `preview-36x48.png` | معاينة سريعة على الشاشة |
| `template/SAIF-poster-template-2026.pdf` | القالب الرسمي كما وصلنا (مرجع الأبعاد) |
| `fonts/ibm-plex/` | IBM Plex Sans Arabic — 5 أوزان + رخصة OFL |
| `assets/flag-sa.svg` | علم المملكة العربية السعودية (متجهي) |

## البناء

```bash
python3 -m venv .venv && . .venv/bin/activate

```

## الالتزام بالقالب

الملصق **يستخدم ملف القالب نفسه** كنقطة بداية، فلا يتغيّر أي شيء من هويته:

- شريط سيف الرسمي في الأعلى (الشعار + الشركاء الخمسة) يبقى كما هو حرفيًا.
- الترويسة الحمراء، والبطاقة البيج، وستّ لوحات بأسمائها الستة (Introduction / Methodology / Results / Innovation / Conclusion / Future Work & References) — نفس الإحداثيات المستخرجة من القالب بالنقطة.
- خانة رمز QR، وخانة رقم الجناح، وخانة علم الدولة — في أماكنها الأصلية، والعلم موضوع فيها.
- سطر «Acknowledgments Statement» في الشريط السفلي.
- الشعار الرسمي لسيف أعلى اليسار دون أي تعديل.

ما أُضيف: المحتوى العربي داخل اللوحات، والعنوان، وأسماء الطلاب والمشرف والمدرسة، ورقم ID.

## المحتوى العلمي

| اللوحة | المضمون |
|--------|---------|
| المقدمة | تعريف الحوسبة الكمية + المشكلة الثلاثية + سؤال البحث + الفئة المستهدفة |
| المنهجية | ثلاث مراحل مرسومة (تحليل / بناء / تحقّق) + شريط «افهم ← جرّب ← تحقّق» |
| النتائج | ستة أرقام محققة + دائرة بيل مرسومة متجهيًا + أشرطة احتمالات 50/50 |
| الابتكار | أربع نقاط تميّز + صندوق «الفرق في البناء» + جدول مقارنة مع المحاكيات العالمية |
| الخاتمة | أثر التجربة + خلاصة رقمية |
| العمل المستقبلي | خطة قياس الأثر + التوسّع + المراجع الثلاثة + رمز QR |

## ملاحظات تقنية

### التصحيح الذي أُجري على الخط
خط IBM Plex Sans Arabic **يحتوي** أشكال الحروف العربية المعزولة (140 شكلًا في نطاق U+FE70–FEFF)، لذا يعمل التشكيل العربي مباشرة دون أي رقع — بخلاف الخطوط التي تفتقد هذه الأشكال وتُظهر مربّعات فارغة. الخطوط الخمسة مضمّنة في الـ PDF بعد تصغيرها (`subset_fonts`) إلى المحارف المستخدمة فقط.

### ملاحظتان على محرّك MuPDF
- `Page.insert_htmlbox` **يفشل بصمت** (يعيد `-1`) عندما يكون ارتفاع الإطار أقصر من سطر واحد — لذلك يتحقق السكربت من كل كتلة ويطبع تحذيرًا.
- المحرّك يعامل `text-align` **منطقيًا** مع اتجاه الفقرة: في سياق RTL تُخرج `left` النص إلى اليمين. يعكس السكربت القيمة تلقائيًا.
- الرسم البدائي لا يقبل ألوانًا نصية (`draw_rect(fill="#0E3F3C")` يرمي استثناء) — تُحوَّل عبر `rgb()`.

### إزالة نصوص القالب المؤقتة
القالب يحتوي على «Student Name: / ID: / Innovation Title / Text here» وغيرها. تُحذف بـ `apply_redactions` مع `PDF_REDACT_IMAGE_NONE` و`PDF_REDACT_LINE_ART_NONE` حتى تبقى الشعارات والرسوم سليمة.

### العلم
الملف لا يحتوي علمًا جاهزًا (خانة مكتوب عليها «Country Flag Here»). يوضع علم السعودية من `assets/flag-sa.svg` عبر `show_pdf_page` بعد تحويله إلى PDF — فيبقى **متجهيًا** ولا يتحوّل إلى صورة نقطية.

## فحص الجودة

```bash
python3 - <<'PY'
import pymupdf
p = pymupdf.open('saif-poster-36x48.pdf')[0]
print(f"{p.rect.width/72:.0f} × {p.rect.height/72:.0f} بوصة")   # 36 × 48
print(p.get_text()[:60])
print('خطوط:', sorted({f[3].split('+')[-1] for f in p.get_fonts()}))
PY
```

آخر تحقق: **0** نص خارج الصفحة، **0** تراكب بين كتل النص، PDF **925 KB**، وكل الكتل داخل أطرها بلا تصغير تلقائي.

### فحص التراكب التلقائي

المولّد يسجّل المساحة المرسومة فعليًا لكل كتلة نص، ثم يقارن كل زوج منها ويطبع تحذيرًا إن تجاوز التداخل 25% من مساحة أصغر كتلة:

```
✓ لا تراكب بين كتل النص
```

هذا الفحص أُضيف بعد خلل حقيقي: فقرتان تتحدثان عن النتيجة نفسها كانتا تُرسمان فوق بعضهما في لوحة «النتائج» (تراكب 34 نقطة)، فبدت الكلمات مشوّهة. لاكتشاف الخلل مبكرًا، جرّب إدخال كتلتين متداخلتين عمدًا — سيطبع السكربت `⚠ تراكب نصوص` مع أسماء الكتل.
